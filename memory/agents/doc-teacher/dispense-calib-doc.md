## 評価用問題
### Q1 運転時キャリブレーションの測定点を 2 点、X 方向だけ 1.5 mm 離して設定した（Y は同じ、`crop_size_mm` は既定）。はんだ塗布ジョブを実行するとどうなるか。どう直せばよいか。
- 要点: 撮影範囲（2 mm 角）が重なる／塗布を始める前にジョブがエラーで止まる（警告で続行ではない）／点を 2 mm 以上離す（または crop_size_mm を 1.5 mm 未満にする）

### Q2 測定点 3 点のうち 2 点目の塗布後撮影に失敗した。補正とジョブはどうなるか。
- 要点: 補正しない（残り 2 点でも補正しない）／警告をログに出す／ジョブは止まらず machine.toml の係数で塗る

### Q3 `amount_ul` 0.2、測定点 3 点、補正前の `rotations_per_ul` 40。1 点が `diameter_below_reliable_range` で不採用、採用 2 点の推定合計が 0.44 µL だった。補正後の `rotations_per_ul` はいくつか。
- 要点: 指令合計は採用 2 点ぶんの 0.4 µL／g = 1.1／40 / 1.1 ≈ 36.4

### Q4 補正前の `rotations_per_ul` が 30 で、比 g が 0.25 と出た。使われる値はいくつで、ログには何が出るか。
- 要点: 30/0.25 = 120 は 3 倍を超える／90 に頭打ち／頭打ちの警告が出る

### Q5 運転時キャリブレーションで補正された `rotations_per_ul` は、次のはんだ塗布ジョブでも使われるか。
- 要点: 使われない／そのジョブの実行内だけで、machine.toml へは書き戻さない／次のジョブは machine.toml の値から始める

### Q6 pad editor で測定点を 3 点置いたのに、はんだ塗布ジョブのログに流量キャリブレーションの行が 1 行も出ない。最初に確かめる設定は何か。
- 要点: `[paste_dispenser.flow_calibration]` の `calibration_file` が空でないか（空だと機能が無効）

### Q7 運転時キャリブレーションのログで `diameter_below_reliable_range` の点が多い。何を疑い、どう対処するか。
- 要点: 直径が被覆域の下端付近（下側 35 %）に入っている／`amount_ul` が小さすぎないかを疑い、大きくする（または被覆域の広い校正を作る）

### Q8 塗布量校正の生成ジョブで、運転者のローディングは塗布前撮影の前と後のどちらに行うか。理由も答えよ。
- 要点: 後（塗布パスの先頭、塗布前撮影の後）／前に行うと数十分の撮影中にプライム状態が抜ける

### Q9 収集ジョブのローディング中、押し出したペーストを銅板の空いている隅に落としてよいか。理由も答えよ。
- R1 で差し替え（旧問は「理由も」が無く、要点の理由を引き出せなかった＝問題不良）
- 要点: 不可。銅板の外へ捨てる／計量した増加質量に混ざり、回転数比の配分で全 sample に系統的なバイアスが乗る

### Q10 収集ジョブの計量質量の入力待ちでブラウザが落ち、入力できないままジョブが終わった。撮影済みデータを確定させるまでに運転者がすることを、順に答えよ。
- R3 で差し替え（旧問「生かすには何をするか」はジョブ名だけの答えを許す粒度で、要点の手順を引き出せなかった＝問題不良）
- 要点（R3 以降）: 銅板を拭かずに TARE した天秤で増加質量を量る → paste_dataset_finalize に増加質量を入れて実行 → プロンプトで pending.json を持つ session を選ぶ
- 要点: `paste_dataset_finalize`（未完了 dataset の確定）ジョブを使う／計量した増加質量を入れ、プロンプトで pending.json を持つ session（`*.incomplete` / `.<stem>.tmp`）を選ぶ／撮り直しは不要

### Q11 同僚が「精度を上げたいので収集の `view_count` を 4 にしよう」と言う。どう答えるか。理由も含めて答えよ。
- R1 で差し替え（旧問は理由を求めていなかった＝問題不良）
- 要点: 周辺 view は検出失敗時のフォールバックで精度は上がらない（view 間ばらつき 1.2 %）／撮影枚数が増えるだけ／0 のままにし、検出失敗が出るときだけ増やす

### Q12 収集で `cell_size` 2 mm、`cell_gap` 0.5 mm、`crop_size` 3 mm と設定した。どうなるか。
- 要点: 装置を動かす前にジョブが失敗する／crop_size はセルピッチ 2.5 mm 以下にする

### Q13 教師体積を配分するとき、blank セルとローディングの回転数は分母 \(\sum_j r_j\) に入るか。
- 要点: どちらも入らない／分母は塗布セルの指令回転数だけ／blank は真値 0、ローディング分は銅板外に捨てるので質量にも入らない

## 保留問題
### H1 運転時キャリブレーションで使う校正ファイルのノズル径が、いまの機体のノズル径と違う。補正は行われるか。
- 要点: 行われる／食い違いをログに出すだけでそのまま補正する

### H2 測定点を 1 点だけにしても運転時キャリブレーションは動くか。推奨は何か。
- 要点: 動く（1 点でも採用できれば補正する）／点ごとの残差 9〜11 % がそのまま補正値に乗る／3 点ほど置く

### H3 以前の収集と同じセル配置・吐出量割り当てで収集し直したい。`shuffle_seed` をどうするか。
- 要点: 0 以外の同じ値を指定する（0 は実行ごとに生成）／以前の値は metadata の `config.shuffle_seed` にある
