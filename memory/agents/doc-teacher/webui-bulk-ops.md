# docs/operations.md 一括管理タブ 理解度テスト

## 対象
- ファイル: `docs/operations.md` の「## 一括管理タブ（複数の機体をまとめて扱う）」節と、「### 更新する」にある同節への 1 行の案内
- 読者と用途: 装置を運用する作業者が、複数の機体をまとめて扱うときに読む。一括管理タブで何ができるか、ボタンが押せる条件、塗布実行が何で動くかを把握して操作する。

## 事実確認（R1 時点、ブランチ feature/2026-10-05/webui-bulk-tab）
- `bulk.html`: 節ごとに表。PnP 節は「PnP の一括操作は未実装です。」を出すが、機体があれば操作権・ソフトウェア列の行は出る。塗布列は paste 節だけ
- `layout.py` `bulk_sections`: paste・pnp 節は機体 0 台でも出る。未設定・未知の machine_type は末尾「種別不明」節（該当があるときだけ）
- `bulk.js`: 更新・塗布実行は state === "held" のときだけ有効。viewer（他人保持）では「取得」が disabled（奪取不可）。unknown では取得も隠れる。行ごとに `/api/ws` を張る（保持者接続 0 本で 30 秒経つと解放、`control.py` disconnect_grace=30）。塗布実行は `POST /api/jobs/paste_solder` に `params: {}`
- `catalog.validate_params`: 未指定は ParamSpec の default で埋める。paste_solder は persisted_params なし → 塗布ページのフォーム値は使われない。既定: tolerance 0.1 mm、amount 0.1 uL、interactive_loading False
- `manager.start`: requires_pcb で PCB 未選択なら ValueError → 400 → bulk.js がトースト
- `resolve_paste_model`: 基板設定ストアの保存済み塗布設定（無ければ machine.toml 既定で全 pad 有効）
- webui.md の操作権: 機体ページでは奪取できる

## 評価用問題
### Q1 一括管理タブで機体 B の行の操作権が「田中 が保持中」と出ている。あなたは機体 B のソフトウェアを更新したい。一括管理タブの行の「取得」で操作権を取れるか。取れないなら、更新できる状態にするには何をするか。
- 要点: 一括管理の行では「取得」を押せない（奪取できない）
- 要点: 行の機体名のリンクから機体のページを開いて奪取する（田中さんの解放を待つ答えも可）
- （R1 で削除: 「操作権が『あなた』になってから更新を押す」。問いは「更新できる状態にするには」なので、要求していない要点だった）

### Q2 機体 A を位置合わせ許容誤差 0.05 mm で塗りたい。機体 A の塗布ページのフォームに 0.05 を入力し、その後で一括管理タブの機体 A の行の「塗布実行」を押してよいか。理由も答えよ。
- 要点: よくない。一括管理の塗布実行は塗布ページのフォームの値を使わない
- 要点: paste_solder の既定値（許容誤差 0.1 mm）で動く
- 要点: パラメータを変えるなら塗布ページから実行する

### Q3 一括管理タブで、行の「塗布」欄が「PCB未選択」の機体の「塗布実行」を押した。何が起きるか。塗布するためには何をするか。
- 要点: ジョブは開始されず、エラーがトーストで出る
- 要点: その機体のページで PCB を選んでから実行する

### Q4 一括管理タブから機体 A の塗布を開始した。塗布の途中で、ほかの機体のページを開かずにブラウザの一括管理タブを閉じた。機体 A の操作権はどうなるか。
- 要点: 30 秒で操作権が解放される
- 要点: 塗布の実行中でも解放される（一括管理タブか機体のページを開いたままにしておく必要がある）

### Q5 PnP の機体 P が登録されている。一括管理タブの機体 P の行でできることと、できないことを答えよ。
- 要点: 操作権の取得・解放とソフトウェア更新はできる
- 要点: ジョブの一括操作（塗布実行など）はできない（未実装）

### Q6 一括管理タブで、誰も操作権を持っていない機体 C を更新したい。押すボタンを順に答えよ。更新が無かった場合と、あった場合にそれぞれ何が起きるかも答えよ。
- 要点: 先に行の「取得」を押し、操作権を「あなた」にしてから「更新」を押す
- 要点: 更新が無ければ結果がトーストで出て終わる
- 要点: 更新があれば確認ダイアログが出て、OK を押すとその機体で更新と再起動が行われる

## 保留問題
### H1 一括管理タブの「塗布実行」で塗布するとき、どの PCB を塗り、pad ごとの塗布設定には何が使われるか。
- 要点: その機体で選択中の PCB（行の「塗布」欄に出ているもの）
- 要点: その PCB について保存済みの塗布設定

### H2 一括管理タブで、機体 D の行に「接続できません」と出ている。この行の「更新」を押せるか。機体 D が復帰したら、表示を戻すために何か操作が要るか。
- 要点: 押せない（操作できない）
- 要点: 操作は要らない。再接続すると表示は自動で戻る

### H3 一括管理タブから塗布を開始した機体の進行を確認し、途中で中止したくなった。どこで行うか。
- 要点: 行の「塗布ページ」リンクから開いた塗布ページで確認・中止する
