# 一括管理ページ（/bulk）SSR 側 理解度テスト

## 対象
- ファイル:
    - `src/web/ui/templates/bulk.html` 先頭の Jinja コメント
    - `src/web/ui/layout.py` の `BULK_PATH` / `BULK_LABEL` / `_BULK_SECTION_TITLES` / `BulkSection` / `bulk_sections` のコメントと docstring
    - `src/web/ui/pages.py` モジュール docstring の ``/bulk`` の行、`bulk_page` の docstring とコメント
- 読者と用途: WebUI を保守する開発者。一括管理ページにセクションや列を足す・機体の並べ方を変える前に読み、セクション分けの規則、SSR が backend へ問い合わせない理由、ルート登録順の制約、header タブが prefix を持たない理由を把握する。

## 評価用問題
### Q1 machine_type が "inspect" の機体を config/machines.toml に登録した。`_BULK_SECTION_TITLES` には何も足していない。この機体は /bulk のどこに表示されるか。
- 要点:
    - 末尾の「種別不明」セクションに表示される
    - 一覧から消えはしない（`_BULK_SECTION_TITLES` に無い machine_type は種別不明へまとめる）

### Q2 PnP 機が 1 台も登録されておらず、machine_type が paste の機体だけがあるとき、/bulk に「PnP」セクションと「種別不明」セクションはそれぞれ出るか。
- 要点:
    - PnP セクションは出る（`_BULK_SECTION_TITLES` のセクションは 0 台でも出す）
    - 種別不明セクションは出ない（該当機体が 1 台以上あるときだけ出す）

### Q3 検査機（machine_type "inspect"）用のセクションを足し、はんだペーストより上に表示したい。セクションの表示順を決めているのはどこで、どう変えるか。
- 要点:
    - `layout.py` の `_BULK_SECTION_TITLES` の並び順が表示順
    - `("inspect", <見出し>)` を `("paste", ...)` より前に置く

### Q4 bulk_page の中で各機体の backend に操作権や PCB の状態を問い合わせ、SSR でテーブルに埋めるように変えたい。この変更はこのコードの方針に沿うか。現状では行の状態を誰がどこから取っているか、そうしている理由も答えよ。
- R1 で問題文を改訂（問題不良）: 旧問題文は「理由」しか問わず、要点 2（bulk.js が取る）を答える動機がなかった
- 要点:
    - 沿わない。SSR は登録済みマシンの一覧だけで描き、backend へ問い合わせない
    - 行の状態は bulk.js が各機体の `/m/{machine_id}/api/**` から取る
    - 理由: 1 台の backend が落ちていてもページ全体が 503 にならず、他の機体の行を使えるようにするため

### Q5 pages.py を整理していて、bulk_page のルート定義を `/{tab}` のルート定義より後ろへ移したくなった。移してよいか。移すと何が起きるか。
- 要点:
    - 移してはいけない。`/{tab}` より先に登録する
    - 後だと /bulk が入口の `/{tab}`（tab="bulk"）にマッチし、マシンへ振り分けられてしまう

### Q6 header の「一括管理」タブのリンクを、他のタブと同じく機体 prefix 付き（`/m/{machine_id}/bulk`）にすべきか。理由も答えよ。
- 要点:
    - しない。prefix なしの `/bulk` にする
    - 一括管理はマシン非依存のページで、各機体の URL 空間（`/m/{machine_id}/…`）に一括管理は無いため（TABS にも入れない）

### Q7 PnP の機体の行にだけ新しい列を足したい。bulk.html で列を出し分けるとき、何を条件にするか。既存の例も 1 つ挙げよ。
- 要点:
    - セクションの machine_type（`section.machine_type == "pnp"`）で切り替える
    - 既存例: 塗布列は machine_type が paste のセクションだけに出る

### Q8 /bulk を表示中に、上部のマシン選択で機体 A を選んだ。どのページへ遷移するか。
- 要点:
    - 機体 A の既定タブ（`/m/<A>/<DEFAULT_TAB>`）
    - 各機体の URL 空間に一括管理が無いため（current_suffix=DEFAULT_TAB）

## 保留問題
### H1 machine_type を設定していない（None）機体は /bulk でどう扱われるか。
- 要点:
    - 末尾の「種別不明」セクションにまとめて表示される

### H2 同じセクションの中で機体はどの順に並ぶか。
- 要点:
    - 登録順。`MachineRegistry.list()` の順で、静的登録順のあとに mDNS 発見順

### H3 登録済みの 3 台のうち 1 台の backend が停止している。/bulk を開くとページはどうなるか。
- 要点:
    - ページは 503 にならず描ける（SSR は backend へ問い合わせない）
    - 他の機体の行は使える。各行の状態は bulk.js が取る
