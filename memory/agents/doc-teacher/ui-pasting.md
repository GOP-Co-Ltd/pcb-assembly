## 評価用問題
### Q1 rotations_per_ul がまだ無い新しい機体で、吐出量キャリブレーション画面を開いた。最初に何をするか。
- 要点: 「ペーストローディング」画面の質量キャリブレーションで初期値を作る（吐出量キャリブレーションは既存値を基準に補正するため）

### Q2 質量キャリブレーションで、回転押出したペーストを量ったあと、「ローディング」欄の回転数を別の値に書き換えてから質量を入力した。このまま適用してよいか。
- 要点: よくない / 計算には欄の回転数・速度・加速度の現在値が使われるので、押し出したときの値に戻してから適用する

### Q3 ペーストローディング画面で X だけ入力し、Y と Z を空欄のまま「ローディング開始」を押した。Y と Z はどうなるか。
- 要点: ホーミング後の位置のまま（移動しない）

### Q4 吐出量キャリブレーションで ① の値を採用したあと、② の途中でジョブを中止した。① の値は残るか。
- 要点: 残る / 採用した時点で machine.toml に保存されている

### Q5 吐出量キャリブレーションで、キャリブレーションメニューが押せるようになった。① のボタンを押す前に何をするか。どの欄を使うか。
- 要点: プライムする / 「ローディング」欄の押出/吸引を使う

### Q6 塗布量校正の生成を始める前に、手動でプライムしておくべきか。ジョブ中のローディングで出たペーストはどうするか。
- 要点: 手動プライムは不要（ジョブがローディングする）/ 押し出したペーストは銅板の外へ捨てる

### Q7 塗布量校正の生成で、最後の増加質量を入力しないままジョブが終わった。集めたデータを活かすには何を使うか。
- 要点: 「未完了ペーストdatasetの確定」

### Q8 ノズルキャップ位置を記録したい。「現在位置を記録」を押す前に必要な操作を順に答えよ。
- 要点: 全軸ホーミング → マシン操作パネルのジョグでノズルをキャップ位置へ合わせる

### Q9 ノズルクリーニング位置を記録するとき、しっかりこするためにノズルをクリーナーへ押し込んだ位置で記録してよいか。
- 要点: よくない / 先端がクリーナー面に触れるだけの位置で記録する / 押し込みは「押し込み量」ぶん実行時に差し引かれる

### Q10 ノズルクリーニング位置が未記録の機体で、はんだ塗布の初回パージが写らなかった。ジョブはどう動くか。
- 要点: こすらずにパージだけやり直す / やり直しても写らなければ塗布へ進まず失敗する

### Q11 テスト塗布基板生成で「KiCad基板を生成」が押せず、プレビューにはみ出したパッドがある。どうするか。
- 要点: 基板を広げる、または繰り返し数を減らす（「配置可能です」が出れば生成できる）

### Q12 ロードセルを較正して SAVE_CONFIG した。この較正値をリポジトリに残すには何をするか。
- 要点: data/config-templates/<マシン名>.<用途>/printer.cfg に手で反映してコミットする

### Q13 LOAD_CELL_CALIBRATE の中で、TARE と CALIBRATE GRAMS=nnn はどちらを先に実行するか。TARE のときの負荷状態は。
- 要点: TARE が先 / 無負荷で行う

### Q14 はんだ塗布画面のパッド編集欄の上にある数値欄を書き換えた。保存操作は必要か。その値はこの基板だけに効くか。
