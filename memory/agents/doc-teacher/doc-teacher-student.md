# doc-teacher-student skill 理解度テスト

## 対象
- ファイル: `.claude/skills/doc-teacher-student/SKILL.md`、`.claude/agents/doc-teacher.md`、`.claude/agents/doc-student.md`
- 読者と用途: この skill でループを回すメインエージェントが、agent の起動・受け渡し・終了判断を誤りなく行う

## 評価用問題
### Q1 R2 に入るとき、R1 で解答した doc-student をそのまま使ってよいか。理由も答えよ。
- 要点: 使わない（毎回新しく起動する）／前の問題と文書を覚えていて測定にならないため

### Q2 doc-teacher が採点するとき、生徒の答えは模範解答と一致しているが、挙げた根拠箇所がその答えを支えていない。判定はどうなるか。
- 要点: 不正解（当て推量とみなす）

### Q3 R5 を終えても不正解が残った。メインエージェントは何をするか。
- 要点: ループを止める／残った問題と原因をユーザーに報告する

### Q4 保留問題はどの時点で生徒に出すか。また、保留問題で不正解が出たら何をするか。
- 要点: 評価用が全問正解した後の汎化確認／その問題を評価用に移して採点と改稿（手順 4）に戻る／2 回目の保留問題は作らない

### Q5 ある問題の誤答を doc-teacher が「誤読」と分類した。次のラウンドでも同じ問題が「誤読」になった。doc-teacher はこれをどう扱うか。
- 要点: 「埋没」か「曖昧」として扱い、文書を直す

### Q6 対象が .claude/skills/foo/SKILL.md で、.agents/skills/foo/ も存在する。仕上げで何をする必要があるか。
- 要点: 同じ改稿を .agents/skills/foo/ にも反映する

### Q7 doc-teacher を起動するとき name を付けるのはなぜか。
- 要点: 後で SendMessage で同じ doc-teacher に採点と改稿を頼むため

### Q8 改稿の結果、文書の行数が前ラウンドより 25% 増えた。doc-teacher は何をしなければならないか。
- 要点: 増えた理由をノートに書く

## 保留問題
### H1 doc-student を起動するプロンプトに書いてはいけないものを 2 つ挙げよ。
- 要点: 模範解答／ノートのパス

### H2 誤答の原因が「埋没」だった。doc-teacher が直し方として最初に検討する手段は何か。
- 要点: 削る

### H3 生徒が文書を読まなくても一般知識だけで正解できる問題が見つかった。メインエージェントはどうするか。
- 要点: doc-teacher に「問題不良」として差し替えさせる
