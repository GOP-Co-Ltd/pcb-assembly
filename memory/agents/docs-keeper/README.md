# docs-keeper の中間メモ

このフォルダには `docs-keeper` agent がドキュメント整備中・整備後に残すノートを置く。

## ファイル形式

ファイル名: `<task-slug>.md`

```markdown
# <タスク名>

## 修正したドキュメント
- README.md: （差分の意図）
- src/.../README.md: （差分の意図）
- docstring: （対象シンボルと修正内容）

## 残した古い記述・理由
（あえて触らなかったドキュメントがあれば、その理由）

## 後続に引き継ぐ事項
（次のフェーズで追記が必要なもの）
```

## 読み手

- 通常は最終 agent なので読み手はユーザーが中心
- 後続タスクで再度 docs-keeper が呼ばれた際の前提として参照
