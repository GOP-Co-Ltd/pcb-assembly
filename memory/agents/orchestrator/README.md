# orchestrator の中間メモ

このフォルダには `orchestrator`（メインエージェント）がチーム進行中の判断を残す。

## ファイル形式

ファイル名: `<task-slug>.md`

```markdown
# <タスク名> 進行ログ

## 委譲構成
（どの agent に何を委譲したか、並列化の判断）

## レビュー裁定
（code-reviewer の指摘ごとの採否。却下した指摘はその理由）

## 計画外の決定
（フロー逸脱・ユーザーへのエスカレーション等と理由）
```

## 読み手

- ユーザーがタスク後の振り返りに使う
- 圧縮 (compact) 後の復旧時に判断構造を読み戻す
