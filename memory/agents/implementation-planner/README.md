# implementation-planner の中間メモ

このフォルダには `implementation-planner` agent が生成した計画書のみを置く。

## ファイル形式

ファイル名: `<task-slug>.md`

```markdown
# <タスク名>

## 概要
（1〜2文。何を、なぜ）

## 公開インターフェース案
（新規・変更する関数/クラスのシグネチャ）

## 実装ステップ
1. ...
2. ...

## テスト観点
- 正常系：
- 異常系：
- エッジケース：

## 想定リスク・トレードオフ
（実装者が判断に迷う点、選択肢の比較）

## 参照
（既存コードや関連skillへのリンク）
```

## 読み手

- `plan-implementer` が必ず読む（実装の起点）
- `code-simplifier` が公開IFを把握するために参照
- `docs-keeper` が変更意図を把握するために参照
