# implementation-planner の中間メモ

このフォルダには `implementation-planner` agent が生成した計画書のみを置く。

## ファイル形式

ファイル名: `<task-slug>.md`

```markdown
# <タスク名>

## 概要
（1〜2文。何を、なぜ）

## 公開インターフェース案
（新規・変更する関数/クラスのシグネチャ）

## 実装ステップ
1. ...
2. ...

## テスト観点
- 正常系：
- 異常系：
- エッジケース：

## 想定リスク・トレードオフ
（実装者が判断に迷う点、選択肢の比較）

## 確認事項
（orchestrator 経由でユーザーに確認したい点。暫定案を添える。無ければ「なし」）

## 参照
（既存コードや関連 skill へのリンク）
```

## 読み手

- `plan-implementer` が必ず読む（実装の起点）
- `spec-test-author` がテスト観点の起点として読む
- `code-reviewer` が仕様準拠の判定基準として参照
- `code-simplifier` が公開 IF を把握するために参照

## 注意

計画書は**書かれた時点の記録**であり、後続コミットで公開 IF が変わっていることがある。実装前に必ず現在のコードでシグネチャを確認する。「シグネチャは確定」と書かれていても鵜呑みにしない。
