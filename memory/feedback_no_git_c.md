通常の git 操作では `git -C` を使わず、カレントディレクトリで直接実行する。

**Why:** カレントディレクトリで作業していれば `-C` は冗長で、どのリポジトリを触っているか読み取りにくくなる。

**How to apply:**

- 作業ツリー内の操作では `-C` を付けない
- **worktree 作業では `git -C` を使ってよい**（別ディレクトリのリポジトリを操作する必要があり、`-C` が最も素直な手段になるため）
- deny リストには登録しない。worktree 運用を阻害するため
