# 立ち上げ

[ドキュメント一覧](../README.md) · 前: [導入](install.md) · 次: [日常の運用](daily.md)

[導入](install.md) を終えた機体を、塗布できる状態まで整える順序と、各段を完了とみなす条件をまとめる。
立ち上げが済んだら [日常の運用](daily.md) へ進む。

## チェックリスト

機体のページの「校正」タブを開くと、最初に「立ち上げチェックリスト」が出る。
下の表の段を上から順に並べ、各段の状態（完了 / 未完了 / 前提待ち）と、残っていることを示す。
段の名前を押すと、その段を行うページへ移る。

未完了の段があるうちは、トップバーに「立ち上げ 3/7」（済んだ段 / 全段）のようなチップが出る。押すとチェックリストを開く。
機体一覧の「立ち上げ」の列にも同じ要約が出る。

- 各段は設定キーと参照ファイルがそろっていれば完了と表示する。日付は見ない
- 未完了の段のうち、前提の段が残っているものは「前提待ち」と表示する
- 装置診断は、直近に実行した結果で判定する。実行するたびに結果を置き換える
- 直近の結果を読めないとき（形式の変わる前に残した結果など）は、装置診断を未完了と表示する。装置診断をやり直せば直る
- machine.toml を読めない間（設定エラー）は、装置診断のほかは判定できないので、未完了か前提待ちになる
- 基準点、ツールヘッドオフセット、吐出量の校正の値は machine.toml の必須の設定なので、machine.toml を読めれば完了と表示する（ツールヘッドオフセットと吐出量は `[solder]` を読めれば）。
    テンプレートから作った machine.toml には別の機体の値が入っているので、新しい機体では完了と出ていても一度行う

## 手順

この表の並びは `src/pcbasm/commissioning.py` の `STEPS` と同じで、テストが一致を確かめる。
前提の段をやり直したら、その後ろの段もやり直す。

1〜3 はどの機体にもある共通の段、4〜7 ははんだ塗布機（machine.toml に `[solder]` がある機体）だけの段。
チェックリストには、その機体の機能の段だけが並ぶ。部品実装だけの機体（`[pnp]` だけ）では 1〜3 で立ち上げが済む。

| #   | 段                                    | 機能                       | 前提                   | 完了の条件                                                                              | やり直す契機                                 |
| --- | ------------------------------------- | -------------------------- | ---------------------- | --------------------------------------------------------------------------------------- | -------------------------------------------- |
| 1   | カメラ校正                            | `camera_calibration`       | なし                   | [camera] の calibration_file があり、焦点 Z が記録されている                            | カメラの取り付け・ピント・解像度を変えたとき |
| 2   | 装置診断                              | `machine_check`            | カメラ校正             | 直近の装置診断が全項目 ok                                                               | printer.cfg・カメラ・スピーカーを変えたとき  |
| 3   | 基準点                                | `reference_point_setup`    | カメラ校正             | [reference_point] に x / y がある                                                       | 基板を固定する治具を動かしたとき             |
| 4   | ノズル位置（キャップ / クリーニング） | `nozzle_cap`               | 装置診断               | キャップ位置とクリーニング位置の x / y / z がある                                       | ノズルキャップやクリーナーを動かしたとき     |
| 5   | ツールヘッドオフセット                | `toolhead_offset`          | 基準点                 | [solder.nozzle.offset] に x / y がある                                                  | ノズルを付け替えたとき、カメラを動かしたとき |
| 6   | 吐出量の校正                          | `dispense_calibration`     | ツールヘッドオフセット | rotations_per_ul、max_dispense_rate、max_fill_speed がある                              | ペーストのロットやノズルを替えたとき         |
| 7   | 塗布量の校正                          | `paste_volume_calibration` | 吐出量の校正           | [solder.volume_correction] の calibration_file が data/paste-volume-calibrations にある | ペーストの種類やノズル径を替えたとき         |

装置診断はカメラの解像度と校正の一致も確かめるので、カメラ校正の前は不合格になる。カメラを校正してから実行する。
塗布量の校正は、作った校正ファイルを塗布ページの「校正ファイル」（運転時補正）で選んで完了になる。
塗布量の校正は 1 時間ほどかかり、電子天秤で銅板を量る。手順は [日常の運用の「集める手順」](daily.md#%E9%9B%86%E3%82%81%E3%82%8B%E6%89%8B%E9%A0%86) にある。
