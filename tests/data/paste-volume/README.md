# 点塗布の円検出テスト素材

`pcbasm.pasting.paste_volume.detect`（塗布前後差分）と
`pcbasm.vision.PasteDotDetector`（塗布後 1 枚の背景差分）の回帰テスト用に、実収集
session から抜いた塗布前後画像。合成画像では背景の銅板テクスチャ・照明ムラ・
ペーストの質感が再現できないため、実データを少量だけコミットしている。

## 出典

`data/paste-volume-datasets/plate-47.5x20-20260909T145923.452+0900`
（`data/paste-volume-datasets/` 自体は `.gitignore` で Git 管理外）

- ペースト: S3X70-E150DN / ノズル径 0.30 mm / 塗布高さ 0.20 mm
- `pixel_per_mm = 28.677782176153425`
- crop 53 × 53 px（`crop_size_mm = 1.8`）
- 収集時の metadata schema は v2。**画像は schema に依存しない**ので、v3 のみ対応に
    なった後もそのまま素材として使える

## 内訳

各 directory に `pre/00.png` `pre/01.png` `post/00.png` `post/01.png`（view 0 と 1）。

| directory | 出典 sample index | 指令量 [µL] | 教師ラベル [µL] | 参考: 検出直径 [mm] |
| --------- | ----------------: | ----------: | --------------: | ------------------: |
| `small/`  |                 8 |       0.050 |          0.0357 |         0.590/0.584 |
| `medium/` |                54 |       0.125 |          0.0892 |         0.762/0.765 |
| `large/`  |                46 |       0.200 |          0.1427 |         0.864/0.866 |
| `blank/`  |                13 |           — |             0.0 |             0.0/0.0 |

教師ラベル（`measured_volume_ul`）は総質量を指令回転数比で配分した値で、この session
では指令量の 0.7135 倍で一定。

校正が当てているのはこのラベルなので、推定値を指令量と突き合わせてはいけない。

`blank/` は塗布していないセル（真値 0）。検出直径が厳密に 0 になることが要件なので、
この素材が回帰の要になる。

## テストで固定してよい値

検出直径は OpenCV のバージョンで下位桁が動きうるので、**具体的な小数値をピンしない**。

- `blank` は `diameter_mm == 0.0`（厳密。閾値ではなく blank ガードの契約）
- `small < medium < large` の順序関係
- 直径がおおよその範囲（0.2〜1.2 mm）に入ること
- 同一セルの view 間ばらつきが相対 15% 以内

## 単一画像検出（`PasteDotDetector`）の参考値

ツールヘッドオフセット計測は塗布前画像を撮れない（観測ごとにステージが動く）ので、
`post/` 1 枚から `MORPH_CLOSE` で背景を推定して差分を作る。背景推定カーネルは
最大直径の 1.5 倍（下の実測はジョブ既定の最大 2.0 mm → 87 px）。

| 素材     | 塗布前後差分の直径 [mm] | 単一画像の直径 [mm] | 重心差 [px] | 円形度 4πA/P² |
| -------- | ----------------------: | ------------------: | ----------: | ------------: |
| `small`  |             0.590/0.584 |         0.589/0.578 |       < 0.3 |     1.02/1.03 |
| `medium` |             0.762/0.765 |         0.759/0.758 |       < 0.3 |     1.00/0.96 |
| `large`  |             0.864/0.866 |         0.856/0.858 |       < 0.3 |     0.96/0.95 |

### 未塗布（`blank`）に残る成分と、2 つの下限の役割

`blank` の分位点コントラストは 48/77 で `min_contrast=20` のガードを抜けるため、
2 値化の残りかすが成分として残る。内訳（view 0 / view 1）:

| 成分             | 直径 [mm] | 円形度    | 弾く条件             |
| ---------------- | --------: | --------- | -------------------- |
| 大きい塊（ムラ） | 1.28/1.18 | 0.17/0.18 | 円形度 >= 0.7        |
| 中くらいの断片   | 0.31/0.26 | 0.62/0.45 | 円形度 >= 0.7        |
| 小片（6-41 px）  | 0.10-0.25 | 0.89-2.09 | 直径下限（既定 0.4） |

**小片の円形度は 1 を超える。** `cv2.arcLength` が画素階段の周長を過小評価するため、
直径 10 px 未満では 4πA/P² が破綻する（r=1 で約 2.0）。したがって

- 円形度の下限（`PasteDotDetector` 既定 0.7）は**大きい**非円形成分を弾く
- 直径の下限（ジョブ既定 `paste_diameter_min = 0.4 mm`）は**小片**を弾く

の 2 つが揃って初めて「未塗布なら検出なし」になる。最小直径 0（下限なし）は
`validate_paste_diameters` が受け付けない。

### 参考: 合成形状での円形度

| 形状                         | 直径 [mm] | 円形度 |
| ---------------------------- | --------: | -----: |
| 円 r=10 px                   |     0.696 |   1.00 |
| 楕円 2:1                     |     1.022 |   0.83 |
| 棒 40x8 px                   |     0.704 |   0.48 |
| 光沢想定の環（外 12 / 穴 6） |     0.708 |   0.74 |

円形度は検出器のパイプライン（`open_kernel_px=3`）を通した値。open が画素階段を
丸めて周長が縮むので、マスクへ直接 `arcLength` をかけた値（環なら 0.69）とは一致
しない。

なお `PasteDotDetector` は数える前にマスクの穴を埋めるので、光沢で中心が抜けた
塗布痕は中実の円と同じ直径・円形度に戻る（上の環も 0.823 mm / 1.00 になる）。
ハイライトが外半径の 2/3 を超えると環が細って open で分断されるため、そこが
検出できる上限。穴埋めは未塗布の判定に影響しない（`blank` の大きい成分は
円形度 0.17 → 0.17 / 0.18 → 0.19）。
