概要

ペーストマシンはノズルの乾燥・詰まりを防ぐため、タスク終了時に必ず ノズルキャップ位置へ移動（Z0 へ退避 → キャップ XY → キャップ Z）してから 脱力する。ここで記録した位置がタスク終了時の駐機先になる。 未記録の間は従来どおり PRESENT（無ければ M84）にフォールバックする。

Y を手前にした位置で記録すれば、駐機と基板取り出しを両立できる。

記録手順

  1. 全軸をホーミングする（未ホーミングでは記録できない）
  2. マシン操作パネルのジョグでノズルをキャップ位置へ合わせる
  3. 「現在位置を記録」を押す（machine.toml の [nozzle_cap] に保存される）
