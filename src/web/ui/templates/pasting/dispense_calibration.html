既存の rotations_per_ul を基準に、銅板へ線を引いて ①→②→③ を順に補正します。 rotations_per_ul の初期値をゼロから作る場合は、先に「ペーストローディング」画面の質量キャリブレーションを使ってください。 ① と ② では線の質量を量るので、電子天秤を用意します。

  1. 未塗布の銅板を装置に置き、「実行」を押す（位置合わせと高さ計測の後、キャリブレーションメニューが押せるようになる）
  2. 「ローディング」欄の押出/吸引でプライムする
  3. ① ② ③ のボタンで補正を実行する（途中の指示はジョブのログに出る）
  4. 「終了（設定反映へ）」を押す

採用した値はその時点で machine.toml に保存され、途中で中止しても残ります。
