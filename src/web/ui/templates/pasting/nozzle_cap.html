ノズルキャップ

ペーストマシンはノズルの乾燥・詰まりを防ぐため、タスク終了時に必ず ノズルキャップ位置へ移動（Z0 へ退避 → キャップ XY → キャップ Z）してから 脱力する。ここで記録した位置がタスク終了時の駐機先になる。 位置が未記録または可動域外のときは、代わりに PRESENT マクロ（無ければ M84 で脱力）を実行する。

Y を手前にした位置で記録すれば、駐機と基板取り出しを両立できる。

記録手順

  1. 全軸をホーミングする（未ホーミングでは記録できない）
  2. マシン操作パネルのジョグでノズルをキャップ位置へ合わせる
  3. 「現在位置を記録」を押す（machine.toml の [paste_dispenser.nozzle_cap] に保存される）

記録位置

ノズルクリーニング

はんだ塗布は初回パージを塗布前後で撮る。ペーストが写らなかったとき（ノズル詰まりの疑い）だけ、次を 1 回行う。

  • 位置を記録済み: ここで記録した位置で少量パージし、十字に往復してノズル先端をシリコンクリーナーへこすりつける。その後パージをやり直す
  • 未記録: こすらず、パージのやり直しだけを行う

やり直しても写らなければ、塗布へ進まずジョブは失敗する。 初回パージ量が 0（無効）の機体では確かめる機会が無いので、クリーニングも行わない。

記録するのはクリーナー面の高さで、押し込みは下の「押し込み量」ぶん 実行時に差し引く。シリコンが摩耗したら押し込み量だけ増やせばよい。

記録手順

  1. 全軸をホーミングする（未ホーミングでは記録できない）
  2. マシン操作パネルのジョグでノズル先端をクリーナー面へ触れるだけ当てる（押し込まない）
  3. 「現在位置を記録」を押す（machine.toml の [paste_dispenser.nozzle_clean] に保存される）

記録位置

{%- if nozzle_clean is not none -%} {{ nozzle_clean.label }} {%- else -%} 未記録 {%- endif -%}

テスト実行

記録した位置と下の動作設定で、はんだ塗布の開始時と同じ手順を 1 回だけ実行し、 最後にノズルキャップ位置へ戻す（接近 → パージ → 十字往復 → 退避 → キャップ）。 押し込み量とこすり幅は結果を見て追い込む値なので、塗布を 1 枚通さずに ここで効き具合を確かめられる。
