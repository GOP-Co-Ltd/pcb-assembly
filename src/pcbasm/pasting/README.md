# pasting

ペースト塗布のドメインロジック。計算・機械手順は本パッケージに置き、ユーザー対話（prompt）・
成果物保存は `web/api/jobs/pasting/` が担う（`pcbasm` は `web.*` を import しない）。
手順のログ・進捗・中断は `hooks.ProcedureHooks` を通してジョブへ渡す（web の `JobContext` がそのまま満たす）。

## 構成

| モジュール               | 役割                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `params.py`              | 塗布パラメータ 10 項目の単一ソース（`[paste_dispenser.defaults]` の型）。`PasteParams` / `PasteParamsPatch` / `PASTE_PARAM_FIELDS`（UI 列順・ラベル・入力種別・描く列）/ `validate_param_values` / `DispenseMotion`（`[paste_dispenser.motion]`）                                                                                                                                                                                                                                                                    |
| `hierarchy.py`           | pad の L0–L4 階層・形状キー・基板の署名。`PadHierarchy` / `PadShapeKey` / `HierKey`                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `overrides.py`           | 基板別の階層 override（L0–L4）の解決と保存。`PasteSettingsModel` / `resolve_pad_settings` / override 集計、保存 `BoardOverrides`（JSON の codec、schema v1）と、選択中の基板 1 枚分の文脈 `BoardSession`（`load_board` の Board → pad 階層 → 署名 → 保存済みの設定）                                                                                                                                                                                                                                                 |
| `fill_path.py`           | pad 1 枚の塗布経路生成（面・線・微小線・点）。`FillPlan` / `FillPlan.build` / `FillPlan.for_pad` / `FillPlan.mode_for_pad`（経路を作らず実際の方式だけを判定） / `paste_height_mm`（点・線・面の塗布高さ） / `amount_per_path_ul`（経路 1 本あたりの塗布量）。塗布 Z（基板表面からのノズル高さ）はこのモジュールだけが決める                                                                                                                                                                                         |
| `pad_editor.py`          | pad 編集画面の view-model。階層ノードごとの実際の塗布方式の集計 `applied_mode_summaries`（「塗布方式」列の補足表示）、初回パージと運転時補正の設定と解決結果 `initial_purge_view` / `flow_calibration_view`、銅箔の表示用の簡略化 `display_rings`                                                                                                                                                                                                                                                                    |
| `fill_sequence.py`       | 1 経路の G-code ビルダー。`FillSequence`（prime → 移動と同期した吐出 → 塗布後の静定待ち → retract と上昇）/ `MicroLineSequence`（上空で prime + 塗布量を押出 → 静定待ち → こすりつけ → 塗布後の静定待ち → 上昇後に retract）                                                                                                                                                                                                                                                                                         |
| `applicator.py`          | ディスペンサー HAL の駆動 `PasteApplicator` / `build_applicator`。`apply` / `deposit_at` / `draw_line` / `load_rotations`                                                                                                                                                                                                                                                                                                                                                                                            |
| `dispense.py`            | HAL 非依存の塗布実績集計 `DispenseSummary`（収集 schema が参照する。`applicator.py` から再公開）                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `route.py`               | 有効 pad の塗布順路 `plan_paste_route`                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `sweep.py`               | 掃引点列の等間隔分割 `sweep_schedule`（dispense_calibration と paste_volume/dataset が共用）                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `initial_purge.py`       | 初回パージ位置（座標）の解決                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `purge_check.py`         | 初回パージを塗布前後で撮って写ったかを確かめ、写らなければノズルを掃除して 1 回だけやり直す `purge_with_cleaning`                                                                                                                                                                                                                                                                                                                                                                                                    |
| `nozzle_clean.py`        | ノズル先端のクリーニング（クリーニング位置でパージ → 十字往復でこすり）。塗布ジョブでは初回パージを撮って塗布を検出できないときだけ実行する。`resolve_nozzle_clean` / `plan_nozzle_clean` / `wipe_points` / `wipe_gcode` / `depart_gcode` / `clean_nozzle`                                                                                                                                                                                                                                                           |
| `height.py` / `probe.py` | 銅箔上のプローブ計測と高さ面 `HeightPlaneMeasurer` / `plan_probe_points` / `ProbeExecutor`、計画点と高さ面の描画 `render_planned_points` / `render_height_plane`                                                                                                                                                                                                                                                                                                                                                     |
| `capture.py`             | board 座標の点をカメラ中心へ置いて固定寸法で切り出す `PointCapturer`                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `dot_capture.py`         | 3 パス撮影（全点の塗布前撮影 → 全点塗布 → 全点の塗布後撮影）`DotCaptureRun`。塗布量の校正の dataset 収集と運転時補正が共用し、prime 後の追加遅延 `PRIME_EXTRA_DELAY` をここだけで決める                                                                                                                                                                                                                                                                                                                              |
| `plate.py`               | 位置合わせしない銅板。外形だけの矩形基板の生成 `write_rect_board` と、高さ計測済みの銅板 `CopperPlate`（板上の全点に使う変換・中心の Z・ノズルの退避）                                                                                                                                                                                                                                                                                                                                                               |
| `session.py`             | 塗布ワークフローの HAL 配線 `PasteSession`（Board 計測結果 → 高さ計測・位置合わせ・pad 別変換・銅板の一括変換・applicator 構築）                                                                                                                                                                                                                                                                                                                                                                                     |
| `plan.py`                | 塗布の前計画 `plan_paste` → `PastePlan`（対象 pad・順路・pad ごとの設定と塗布経路・初回パージ・運転時補正）。pad 編集画面の preview と塗布ジョブが共用する                                                                                                                                                                                                                                                                                                                                                           |
| `labels.py`              | 表示文字列。座標の書式 `fmt_xy` / `fmt_xyz` と、初回パージ・クリーニング位置・運転時補正のラベル                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `hooks.py`               | 手順がジョブへログ・進捗・中断・画像の表示を渡す口 `ProcedureHooks`                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `prepare.py`             | 塗布の前の補正の計測 `prepare_paste`（高さ面 + `align.align_board`）と、その結果 `PasteCorrection`                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `toolhead_offset.py`     | カメラ–ノズル間オフセット計測 `ToolheadOffsetProcedure` / `ToolheadOffsetResult` / `ToolheadOffsetDiagnostics`                                                                                                                                                                                                                                                                                                                                                                                                       |
| `dispense_calibration/`  | 吐出の事前校正（旧 flowcalib）。`params`（ジョブ既定値）/ `mass`（質量 → rotations_per_ul、レート・速度掃引の数理）/ `lines`（線配置と掃引計画）/ `procedure`（計測済みの銅板と applicator を束ねる機械手順）                                                                                                                                                                                                                                                                                                        |
| `test_board/`            | テスト塗布基板の KiCad 生成。`config`（設定 DTO と検証）/ `catalog`（footprint 検索とパッド種解決）/ `layout`（パッド packing）/ `generator`（preview・`.kicad_pcb` 生成のファサード）                                                                                                                                                                                                                                                                                                                               |
| `paste_volume/`          | 点塗布の円直径から塗布量を推定する校正。`detect`（pre/post 画像から面積等価直径を測る。差分・2 値化の実装は `pcbasm.vision.dot`）/ `aggregate`（view 中央値）/ `model`（切片 0 固定の 3 次）/ `calibration`（校正ファイル schema v1）/ `estimator`（公開 prediction API）/ `fit`（1 session → 計測 → フィット → 診断）/ `evaluate`（校正 × session → 誤差レポート）/ `runtime_correction`（運転時補正: 測定点の検証、3 パス撮影での実行、`rotations_per_ul` 補正の算出）/ `dataset/`（下記）/ `plot`（校正の診断図） |
| `paste_volume/dataset/`  | ペースト塗布画像 dataset の収集（銅板のセル格子へ点塗布）。`plan`（セル格子・量スイープ・view・事前検証）/ `metadata`（metadata.json DTO・codec、schema v3）/ `pending`（計量質量の入力前に退避する pending.json）/ `store`（一時 session への書き込みと atomic 確定、未確定 session の救出）/ `reader`（完成 session の列挙と読み出し）/ `recorder`（撮影・塗布結果の蓄積と metadata 組立）。撮影は dataset 外の `pasting/dot_capture.py` が行い、`recorder` が結果を受け取る                                       |

サブパッケージ行に並ぶ `detect` などの名前は、そのディレクトリのモジュール（例: `paste_volume/detect.py`）を指す。

`__init__.py` は docstring のみで re-export しない。消費側はサブモジュールを直接 import する
（`import pcbasm.pasting` が cv2 / pcbnew を引き込まない契約を `tests/test_package.py` で固定）。
固定しているのは re-export しないことであって、サブモジュール自身が重い依存を持たないことではない。

塗布量推定は `paste_volume/` の円直径の 3 次近似ひとつ。Raspberry Pi の WebAPI
プロセスでそのまま動く（cv2 / numpy は base 依存）。

`dispense.py` は HAL 非依存の値だけを置く。収集 schema（`paste_volume/dataset/metadata.py`）を学習側から
読むとき `pcbasm.hal`（picamera2 を要求する）を引き込まないため、`DispenseSummary` を
`applicator.py` から分離してある。

## 依存方向

```
web/api/jobs/pasting/*  →  pasting.{plan,purge_check,dispense_calibration.procedure,toolhead_offset,
                                    paste_volume.{runtime_correction,dataset.*}}
                              ↓
                       pasting.{plate,dot_capture,capture}
                              ↓
                       pasting.{session,prepare}
                              ↓
                       pasting.{applicator,fill_path,fill_sequence,params,hierarchy,overrides,route,
                                initial_purge,height,probe,nozzle_clean,labels,hooks}
                              ↓
                       pcbasm.{config,geometry,board,kicad,align,vision,hal}
```

- 矢印は `pasting` の中の import の向き。ジョブは `session` / `overrides` / `prepare` / `plate` などの下の段も直接使う
- `dot_capture` は撮る view の型 `DatasetView` を `paste_volume.dataset.metadata` から借りる（dataset は撮った view をそのまま記録する）
- `nozzle_clean` は塗布ジョブのほかに、基板を使わないテストジョブ（`web/api/jobs/pasting/nozzle_clean_test.py`）からも呼ぶ。
    `PasteSession` を介さず `Klipper` / `XYZStage` / `PasteApplicator` だけで完結させてあるため
- `overrides` と `plan` / `pad_editor` はジョブ以外に pad 編集 API（`web/api/routers/pasting/board.py`）からも使う。
    `BoardOverrides` は backend のプロセスで 1 つを共有する（pad PATCH をそのロックで直列化するため）
- 汎用の計算幾何は `pcbasm.geometry`、KiCad 汎用処理は `pcbasm.kicad`（`units` / `footprint` / `build`）に置く
- 永続 JSON（基板別 override / dataset metadata / 塗布量の校正 / テスト塗布基板 document）は `pcbasm.document` の strict な変換で読む
    （未知 key・欠落 key・暗黙の型変換を拒否する）。版が違えば拒否し、旧版を読むときは純関数 `_migrate_vN` で新版 dict へ写してから structure する。
    形状を変えない限り版は上げない

## 規約

| 対象           | 規約                                                                                                                                                                                            |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 接頭辞         | `Paste*` = 塗布ドメイン名詞、`Dispense*` = 吐出ダイナミクス、`Fill*` = 経路と G-code、`Flow*` = 流量キャリブ                                                                                    |
| 単位           | μL は常に `_ul`（`amount_ul`, `volume_ul`）。密度は `density_mg_per_ul`（TOML キー `solder_paste_density` は config プロパティで橋渡し）。mm は幾何値では無記、JSON DTO と KiCad 境界だけ `_mm` |
| 検証           | 検証関数 `validate_<対象>()` と検証メソッド `validate()` は、問題があればエラー文（`str`）、問題が無ければ `None` を返す。例外は投げない                                                        |
| 値オブジェクト | `attrs.frozen` + tuple。新規 ABC は作らない。Protocol は呼び出し側が満たす口（`ProcedureHooks` / `DotCaptureSink`）だけ                                                                         |
| ログ           | モジュールごとの `logging.getLogger(__name__)`。運転者に見せる経過は `ProcedureHooks` で渡す。複数回機械を動かすメソッドだけ `checkpoint` コールバックか `ProcedureHooks` を受ける              |

位置合わせは `align` を利用する。
